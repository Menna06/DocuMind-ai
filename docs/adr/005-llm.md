# ADR-005: Large Language Model

## Status

Approved

## Decision

OpenAI Chat Completions API (GPT-4.1 or latest stable GPT model)

## Context

The system must generate grounded natural language responses from retrieved document context.

## Alternatives Considered

- Local open-source models
- Anthropic Claude
- Google Gemini

## Rationale

Using a hosted LLM enables focus on retrieval, prompt engineering, orchestration, and software architecture rather than model infrastructure.

## Consequences

- Requires OpenAI API key
- Token usage costs apply per query
- Model selection configurable via environment variables
