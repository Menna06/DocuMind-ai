# ADR-001: Programming Language

## Status

Approved

## Decision

Python

## Context

DocuMind AI requires a language with mature AI/ML ecosystem support for RAG pipeline development.

## Alternatives Considered

- Java
- C#
- Node.js

## Rationale

Python is the industry standard for AI Engineering due to its mature ecosystem, excellent library support, readability, and widespread adoption across AI platforms.

## Consequences

- Full access to LangChain, ChromaDB, and OpenAI SDKs
- Aligns with industry hiring expectations for AI Engineering roles
